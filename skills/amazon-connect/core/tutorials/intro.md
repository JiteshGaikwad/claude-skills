# Tutorials (Administrator Guide)

This folder paraphrases the Administrator Guide’s “Tutorials: An introduction to Connect Customer” so you can execute the same learning path while staying inside this repo.

The tutorial series is designed to:

1) create an instance and claim a number,
2) test the sample voice + chat experience (no development required),
3) build a simple IT Help Desk that uses Lex, routing, and a custom flow.

Prerequisite (called out by the Admin Guide):
- An AWS account.

Tutorials:
- `core/tutorials/01-set-up-instance.md`
- `core/tutorials/02-test-sample-voice-chat.md`
- `core/tutorials/03-it-help-desk.md`
